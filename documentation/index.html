Welcome to Kora

Write Less. Build Faster. Run Smarter. A compiled backend programming language and framework unifying TypeScript's approachable developer experience, Rust's bare-metal performance, and Go's clean concurrency.

Compiler-Guaranteed Clean Architecture
Unlike traditional dynamic frameworks where architectural rules are merely suggestions, Kora statically enforces Clean Architecture rules at compile time through codes E5001 to E5004.

A Taste of Kora (10-Line Microservice)

Building a high-throughput, type-safe API with Kora requires zero boilerplate:

kora 
@table("greetings")
model Greeting {
    @id
    id: Int
    message: String
    timestamp: Int
}

class GreetingRouter {
    init() {}

    fn registerRoutes(app: App) -> Unit {
        get("/api/v1/hello", () => {
            return Response.json(Greeting {
                id: 1,
                message: "Hello from Kora!",
                timestamp: 1773000000
            })
        })
    }
}

class Application {
    init() {}

    fn bootstrap() -> Unit {
        let app = run()
        app.use(GreetingRouter)
        app.listen(7582)
    }
}

let app = Application()
app.bootstrap()
