Concurrency, Actors & Stream Pipelines

Kora eliminates data races at compile time using structured concurrency, Erlang-inspired isolated Actor mailboxes, bounded MPSC channels, and zero-allocation stream pipelines.

1. The Actor Model

Actors represent autonomous, state-isolated lightweight execution units that communicate solely via message passing:

kora 
// Actor definition
actor CounterActor {
    count: Int = 0

    receive(msg: Int) {
        this.count = this.count + msg
    }
}

// Fire-and-forget message dispatch (tell)
let counter = spawn(CounterActor)
counter.tell(5)

// Request-response with deterministic timeout (ask)
let current = counter.ask("GET_VALUE", 1000)

2. Bounded MPSC Channels

To prevent out-of-memory errors during high-volume spikes, Kora enforces bounded channel capacities:

kora 
// Bounded channel with capacity of 1000 items
let (sender, receiver) = channel<String>(1000)

spawn(() => {
    sender.send("Telemetry Event 101")
})

3. Stream Processing Pipelines

Kora's stream engine processes real-time event sequences with zero intermediate memory allocations:

kora 
let sensorStream = Stream.from([12, 45, 88, 23, 95, 14])

let criticalAlerts = sensorStream
    .filter((temp: Int) => temp > 50)
    .map((temp: Int) => "CRITICAL_TEMP: " + temp)
    .collect()
