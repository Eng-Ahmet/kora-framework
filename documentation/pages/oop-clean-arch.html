Clean Architecture OOP & Invariants

Object-Oriented Programming & Clean Architecture

Kora provides a deterministic hybrid object model where classes encapsulate logic, interfaces declare contracts, and models represent data.

The Five Building Blocks

  • model: Schema entities, database tables, and request/response DTOs.
  • struct: Lightweight value types for structured data.
  • interface: Pure structural contracts enabling dependency inversion.
  • class: Stateful service/controller components with constructor injection (init).
  • enum: Algebraic tagged unions with variant payloads.
Strict Model-Class Segregation
It is strictly forbidden to declare enum or model blocks inside a class body. All domain models and enums must be placed at the top-level or imported from dedicated modules (e.g. models/*.kora).

Compile-Time Clean Architecture (E5001 - E5004)

The compiler evaluates every module against Clean Architecture invariants:

Diagnostic Rule Description Compiler Fix
E5001 Direct infrastructure instantiation inside controllers Inject dependency via init(...) parameter
E5002 Service depending on concrete database instead of interface Depend on interface UserRepository
E5003 Returning raw domain entity across API boundary Map entity to a dedicated model UserDto
E5004 Circular dependency between architectural layers Invert dependency using interfaces

HTTP Routing & app.use() Pattern

Route endpoints are always registered inside a dedicated Router class and mounted using app.use(RouterClass):

kora 
// routes/user.routes.kora
import { UserService } from "../services/user.service"

class UserRouter {
    service: UserService

    init(service: UserService) {
        this.service = service
    }

    fn registerRoutes(app: App) -> Unit {
        get("/users", (router: UserRouter) => {
            return Response.json(router.service.listUsers())
        })

        get("/users/{id}", (id: Int, router: UserRouter) => {
            return Response.json(router.service.getUser(id))
        })
    }
}

// main.kora
class Application {
    init() {}

    fn bootstrap() -> Unit {
        let app = run()
        app.use(UserRouter)
        app.listen(8080)
    }
}

let app = Application()
app.bootstrap()
