Language Tour & Fundamentals

Kora provides a modern, expressive syntax designed for developer ergonomics with optional semicolons, complete type inference, and native memory safety.

Variables & Type Inference

Variables are declared using let. Kora's compiler utilizes Hindley-Milner bidirectional type inference:

kora 
// Inferred types
let count = 42             // Inferred as Int
let rate = 0.15            // Inferred as Float
let label = "production"   // Inferred as String
let isActive = true        // Inferred as Bool

// Explicit type annotation (optional)
let threshold: Int = 100
let price: Decimal = 49.99

Primitive Type System

Type Description Example Literal
Int / Int64 64-bit signed integer (default) 42, -100
Int32, Int16, Int8 Sized signed integers 120: Int32
UInt / UInt64 64-bit unsigned integer 100: UInt
Float / Float64 64-bit IEEE 754 floating point 3.14159
Decimal Arbitrary precision financial decimal 199.95: Decimal
String UTF-8 encoded heap-allocated string "Welcome to Kora"
Bool Boolean true or false true, false
Unit / void Empty return type (analogous to ()) ()

Functions & Lambda Closures

Functions are declared with fn, while closures use concise arrow notation (args) => expr:

kora 
// Standard named function
fn calculateTax(subtotal: Int, ratePercent: Int) -> Int {
    return (subtotal * ratePercent) / 100
}

// Arrow closure passed to higher-order function
let numbers = [1, 2, 3, 4, 5]
let doubled = numbers.map((n: Int) => n * 2)

Control Flow & Pattern Matching

Kora supports if/else, for..in, while, break, continue, and exhaustive match statements:

kora 
enum OrderStatus {
    Pending
    Processing
    Completed
    Cancelled(String)
}

let status = OrderStatus.Cancelled("Customer requested cancellation")

match status {
    OrderStatus.Pending => println("Order awaiting fulfillment")
    OrderStatus.Processing => println("Order packing underway")
    OrderStatus.Completed => println("Order delivered")
    OrderStatus.Cancelled(reason) => println("Order aborted: " + reason)
}

Null-Coalescing & Operators

Kora provides the null-coalescing operator ??, compound assignments, and structured error handling with try/catch/finally:

kora 
let fallbackHost = request.header("X-Forwarded-Host") ?? "127.0.0.1"

try {
    let data = readFile("/etc/config.json")
    processConfig(data)
} catch (err) {
    println("Error reading configuration: " + err)
} finally {
    cleanupBuffer()
}
